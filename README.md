## Descripción
Este repositorio contiene la solución de la tarea sobre gestión de recursos en un data center para el curso de Análisis y Diseño de Algoritmos.

El trabajo aborda dos crisis:
- **Crisis 1:** programación de tareas usando un enfoque greedy.
- **Crisis 2:** asignación de memoria a máquinas virtuales usando programación dinámica.

También incluye la implementación funcional de la Crisis 2.
